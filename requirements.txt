# Jarvis dependencies.
#
# The core task/memory layer (what runs today) needs NOTHING here - it is pure
# Python standard library, so your task record can never break from a bad
# dependency. The packages below get installed as we build each later layer.

# --- Brain: Claude via the official Anthropic SDK ---
# Jarvis's brain is Claude (default model: claude-haiku-4-5), reached through the
# anthropic SDK. Billing is pay-per-token via console.anthropic.com; put the key
# in .env as ANTHROPIC_API_KEY. Swap models with JARVIS_LLM_MODEL (no code change).
anthropic>=1.8

# --- Homelab connectors (system monitoring) ---
# psutil reads local PC stats (CPU/RAM/disk/uptime) for the system-status tool.
# The Plex/*ARR and netdata calls use only the stdlib (urllib), no package.
psutil>=5.9

# --- Calendar: Apple Calendar via iCloud CalDAV (read-only) ---
caldav>=1.3

# --- Interface: Discord bot (capture tasks + reminders + notifications) ---
# Voice needs discord.py 2.7+ and `davey`: as of 2026-03-02 Discord GLOBALLY
# enforces DAVE (MLS end-to-end voice encryption). Older gateways are rejected
# (WebSocket 4006) and opting out of DAVE is rejected too (4017), so the bot must
# speak DAVE to connect at all. Jarvis can therefore JOIN and SPEAK in a VC, but
# HEARING users is currently blocked: discord-ext-voice-recv does not yet decrypt
# DAVE audio (inbound frames fail opus decode with "corrupted stream"). Receiving
# will work once voice-recv implements DAVE decryption (davey exposes
# DaveSession.decrypt); track https://github.com/imayhaveborkedit/discord-ext-voice-recv
discord.py>=2.7
davey>=0.1                  # required by discord.py 2.7+ to use voice at all
PyNaCl>=1.5                 # voice encryption (required to join voice channels)
discord-ext-voice-recv>=0.5 # receive/decode other users' voice (not in core discord.py)
# Voice-channel playback also needs ffmpeg on PATH (system install, not pip).

# --- Natural-language dates ("next Friday", "in 3 weeks") -> resolved in code,
#     not by the model, which is unreliable at weekday math. ---
parsedatetime>=2.6

# --- Config / secrets ---
# Loaded by a tiny stdlib parser in config.py; python-dotenv is NOT required.

# --- Voice: speech-to-text + text-to-speech, run on CPU ---
faster-whisper>=1.2   # STT (Whisper via CTranslate2)
kokoro-onnx>=0.6      # TTS (Kokoro via onnxruntime; no PyTorch needed)
sounddevice>=0.5      # microphone capture + audio playback
soundfile>=0.13       # audio file I/O (testing/round-trip)
# Silero VAD (voice-channel endpointing) needs no extra package: it runs on the
# onnxruntime that kokoro-onnx already pulls in, and the ~2 MB model downloads
# into data/models/ on first use (see src/jarvis/voice/vad.py).
# Model files (kokoro-v1.0.onnx, voices-v1.0.bin) download into data/models/.
